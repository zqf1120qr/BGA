### 一、系统简介与适用场景

**BGA 智能工业质检工作站 (BGA AI Inspector)** 是一款面向高端 SMT 表面贴装、半导体先进封装与 PCB 组装生产线的高精度自动化 X-Ray 探伤智能质检系统。

本系统集成了深度学习目标定位、自适应网格拓扑重构、微小空洞超精细分割与多焊球近邻间隙动态分析技术，针对 BGA（球栅阵列）封装在回流焊接中常见的 **空洞超标 (Voiding)**、**连锡桥接 (Bridge)**、**少锡虚焊 (Insufficient Solder)** 以及 **焊球缺失 (Missing Ball)** 提供一站式全自动、亚像素级精密测量与质量判定。

#### 核心价值：
- **替代人工目检**：消除肉眼疲劳与主观判断差异，质检重复性达到 100%。
- **毫秒级全检**：百颗焊球阵列单片分析耗时低至数十毫秒，满足在线快速全检节拍。
- **IPC 国际标准对齐**：内置符合 IPC-A-610 标准的缺陷判据算法与灵活容差配置。
- **全链路闭环存证**：提供结构化数据工单（Excel）与合规 A4 工业质检报告（PDF）导出。

### 二、硬件环境与部署规范

#### 1. 运行平台要求
- **操作系统**：Windows 10 / Windows 11 (64 位)
- **内存建议**：8 GB 及以上（推荐 16 GB）
- **屏幕分辨率**：推荐 1920 × 1080 及以上（工作站采用自适应缩放设计，高分屏可完美展示）

#### 2. 全能硬件自适应架构（双引擎支持）
本工作站采用智能感知硬件技术，无需用户手动配置驱动：
- **GPU 极速推理模式**：当检测到主机搭载支持 CUDA 的 NVIDIA 独立显卡时，系统自动调用显卡张量算力与 FP16 半精度加速，实现高速推理。
- **CPU 工业级高保真降级模式**：若部署在普通工控机、Intel/AMD 核显轻薄本或未配置独立显卡的机台，系统自动无缝切换为多核 CPU 并行计算，**保证 100% 稳定运行，绝不报错或闪退**。

#### 3. 部署目录规范
解压或分发后的软件包具有如下纯净结构：
```text
BGA_AI_Inspector/
├── BGA_AI_Inspector.exe        # [核心主程序] 双击直接运行
├── 用户操作与部署手册.txt       # [现场文档] 纯文本即查指南
├── backend/                    # [外部扩展] 模型权重目录
│   └── best.pt                 # 外部优先加载权重 (可热替换)
└── _internal/                  # [底层运行时] 核心算法二进制库 (系统依赖，严禁改动)
```
> **安全说明**：本软件包为工业二进制封装，所有核心源码与算法均封闭为底层机器码，无明文脚本泄露风险；且不包含任何开发测试样本图片，安装包体积精简纯净。

### 三、快速上手与日常操作流程

#### 步骤 1：启动工作站
在软件根目录下直接双击 `BGA_AI_Inspector.exe` 启动程序。
系统将自动完成硬件感知与后台算法初始化，弹出深色工业质检主界面。

#### 步骤 2：导入待检图像
在左侧【质检控制面板】中：
- 若质检单张样品：点击 **【选择单张图像】**，在弹窗中选择待检的 X-Ray 图像（支持 `.jpg`, `.png`, `.bmp`, `.tiff` 等常见格式）。
- 若批量多批次质检：点击 **【选择批量文件夹】**，选中包含多张图像的文件夹，底部缩略图画廊将自动加载全部样本。

#### 步骤 3：确认与微调质检参数（可选）
在右侧【质检参数调谐面板】中确认当前工单对应的容差阈值（系统默认提供符合 IPC 标准的基准值，一般无需调整；换线或针对特殊工艺要求时可灵活调整）。

#### 步骤 4：一键执行检测
点击左侧面板的高亮主按钮 **【开始执行质检】**。
- 系统后台多线程将并发执行：深度检测 ➜ 拓扑网格补齐 ➜ 四维缺陷精密筛查 ➜ 报表数据组织。
- 检测耗时通常为数十至数百毫秒，界面实时刷新，视口以醒目色框呈现焊球及缺陷标注。

#### 步骤 5：结果查验与缺陷追溯
- 观察右侧面板的 **【质检概览】**（合格率、总球数、各缺陷类型统计）。
- 点击右侧面板下方的 **【缺陷焊球明细表】** 中的任意缺陷行，中央视口将自动对焦并高亮该焊球，显示具体缺陷数值。
- **长按键盘【空格键】(Spacebar)** 可即时透视原图与标注图进行人工复核。

#### 步骤 6：质检报表一键导出
点击左侧面板底部的导出按钮：
- **【导出 Excel 报表】**：生成包含所有焊球坐标、尺寸、空洞占比、桥接距离及裁定结果的明细工单。
- **【导出 PDF 报表】**：生成符合 A4 工业品保标准的正式质检合格证/判定报告，附带原图、缺陷图与统计图表。

### 四、界面功能分区详解

工作站采用工业级深灰防眩光配色方案，分为四大核心区域：

```
+-----------------------------------------------------------------------------------------+
| [顶部标题栏] 软件标识 | 状态指示灯 | 视口缩放控制按钮组 | 窗口最小化/最大化/关闭        |
+-----------------------------------------------------------------------------------------+

| • 质检执行按钮    | • 绿色/红色/黄色自适应标注圆                 | • 质检数据统计仪表盘 |
| • 质检报表导出    | • 悬停 Tooltip 焊球参数卡                    | • 缺陷焊球明细数据表 |
|                   | • 空格键原图无缝比对                         |                      |
+-----------------------------------------------------------------------------------------+
| [底部缩略图画廊] 批量样品队列快速切换与检测状态角标标记                                 |
+-----------------------------------------------------------------------------------------+
```

1. **左侧控制面板 (Control Panel)**：
   - 负责样品输入源的控制（单张/批处理文件夹）；
   - 展示当前工作站的运行状态指示；
   - 质检报表输出控制（Excel / PDF）。
2. **中央高精度交互视口 (Interactive Viewport)**：
   - 工业级抗锯齿渲染视口，支持数千万像素高精图像毫秒级重绘；
   - 动态几何标注覆盖：正常焊球（绿色）、空洞超标（橙色）、连锡桥接（红色双球连接线）、少锡虚焊（紫黄色）、漏检补齐（虚线标记）。
3. **右侧质检与参数面板 (Inspection & Defect Panel)**：
   - 上半部分：四维参数微调滑块与阈值数字框；
   - 中间部分：质检结果统计总览卡（良品率、缺陷总数、良品数等可视化环形饼图）；
   - 下半部分：缺陷明细表格，支持表项点击交互联动。
4. **底部批量缩略图画廊 (Thumbnail Gallery)**：
   - 支持多张样本流水线预览与自由切换；
   - 每张缩略图带有质检状态图标（待检测 / 合格 PASS / 不合格 NG）。

### 六、四维质检算法与缺陷判据参数调谐

工业现场针对不同的芯片型号（如 0.4mm pitch、0.5mm pitch 微间距 BGA）、回流焊温度曲线与锡膏配方，允许在右侧面板随时针对四维缺陷进行阈值微调：

#### 1. 空洞缺陷 (Voiding)
- **物理机理**：助焊剂残留气体在焊点凝固时未能逸出，形成微气孔。
- **核心参数**：
  - **最大允许空洞率 (%)**：默认值 `15.0%`。根据 IPC-A-610 标准，焊点单一空洞或总空洞投影面积占焊球球体总面积超过 15%~25% 时判定为 NG。
  - **最小有效空洞阈值 (px)**：过滤因 X-Ray 传感器底噪造成的极微小白噪点（建议保持默认 2~5 像素）。

#### 2. 连锡/桥接缺陷 (Bridge)
- **物理机理**：焊膏印刷偏位或回流时焊锡流动塌陷，导致相邻焊球之间发生短路粘连。
- **核心参数**：
  - **桥接间隙敏感度系数**：默认值 `1.0`。系统动态计算全阵列焊球中心间距标准差，当相邻两焊球外边缘间隙压缩至正常球间距的阈值比例以下，即刻报警并在视口中以粗红线高亮桥接路径。

#### 3. 少锡/虚焊缺陷 (Insufficient Solder)
- **物理机理**：钢网开孔堵塞、漏印或焊膏量不足，导致焊球体积明显偏小。
- **核心参数**：
  - **焊球缩减判定比率 (%)**：默认值 `75.0%`。系统自动统计全局焊球平均半径 $R_{avg}$，若某焊球半径 $R < 0.75 \times R_{avg}$，自动判定为少锡。

#### 4. 漏焊/焊球缺失 (Missing Ball)
- **物理机理**：贴片掉球、焊球未润湿或焊盘氧化未能成球。
- **判定逻辑**：系统基于拓扑网格智能重构算法（Grid Topology Refiner），根据阵列周期性对芯片外周与内部进行漏检补齐，对缺失焊盘自动用虚线标出“MISSING”警示。

### 七、质检报表导出与归档

系统支持质检数据全周期数字化存档，点击左侧按钮即可保存：

#### 1. Excel 详细数据工单 (.xlsx)
- 导出文件包含两张核心工作表：
  - **【检测概要表】**：芯片型号、检测时间、总焊球数、合格率、良品数、缺陷数统计；
  - **【焊球明细表】**：每颗焊球的序号、阵列行列号、像素中心坐标 $(X, Y)$、等效半径、空洞面积率、是否桥接、最终质量裁定 (PASS / NG) 及具体缺陷类型。

#### 2. A4 工业级 PDF 质检合格证报告 (.pdf)
- 符合品保归档与出货检验标准的标准 A4 文档，内置：
  - 工业质检报告抬头与防伪单号；
  - 设备运行环境与算法版本号；
  - 待检样品高清缩略图与质检结果标注图；
  - 质量判定结论印章（PASS 绿色合规印章 / REJECT 红色不合格印章）；
  - 缺陷分类分布统计图表与品保工程师签字栏。

### 八、产线模型热替换升级机制

为了适应新产品导入（NPI）与新工艺快速上线，系统创新设计了**外部模型热替换架构**：

1. **工作机制**：
   - 软件内部自带一份出厂标定的基准模型权重；
   - 每次软件启动时，优先扫描运行目录下的 `backend/best.pt`；
   - 如果检测到外部 `backend/best.pt` 存在，系统将**自动优先加载外部最新模型**；如果不存在，则平稳读取内置默认模型。
2. **现场模型升级步骤**：
   - 步骤 ①：关闭正在运行的 `BGA_AI_Inspector.exe` 工作站；
   - 步骤 ②：将算法工程师交付的新版本权重文件重命名为 `best.pt`；
   - 步骤 ③：拷贝并覆盖到工作站根目录下的 `backend/best.pt`；
   - 步骤 ④：重新双击打开 `BGA_AI_Inspector.exe` 即可生效。
   > **优势**：产线完全无需重新打包编译软件，无需重新安装，实现秒级热更新！

### 九、常见问题排查与维护 FAQ

#### Q1: 双击 `BGA_AI_Inspector.exe` 启动时，为何需要等待 2~3 秒？
- **解答**：软件打包为方案 B 二进制封装包，启动时底层系统会自动初始化深度学习推理引擎（PyTorch 核心与计算图算子库），并在后台完成硬件拓扑感知（自动嗅探 GPU/CPU 算力）。2~3 秒属于常规初始化时间，进入界面后后续的每张检测均处于毫秒级高速响应状态。

#### Q2: 软件运行中没有看到 GPU 使用率升高，怎么判断是否使用了显卡？
- **解答**：启动时可在左侧控制面板查看硬件指示灯：若显示 `GPU 加速就绪 (CUDA)`，则表示已成功接入英伟达显卡；若显卡驱动版本过低或为核显机型，系统会自动平滑降级为 `CPU 多线程模式`，检测算法与精度与 GPU 模式完全一致，仅单帧推理耗时略有区别。

#### Q3: 软件支持导入中文路径的图片吗？
- **解答**：100% 支持。系统底层图像加载引擎采用宽字符内存流解码，支持任意深度包含中文、空格及特殊符号的文件路径，绝不会出现路径乱码或无法读取的情况。

#### Q4: 检测完成导出的 PDF 或 Excel 报表保存在哪里？
- **解答**：点击导出按钮时，系统会弹出原生保存文件对话框，您可以自由选择保存至桌面、D盘或者企业局域网共享盘中，默认为当前质检工单名称加时间戳命名，防止文件互相覆盖。
