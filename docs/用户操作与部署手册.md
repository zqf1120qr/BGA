## 1. 产品概述与核心能力

**X射线智能工业质检工作站（X-ray AI Inspector）** 是面向高端 SMT 表面贴装、半导体先进封装及 PCBA 组装产线打造的自动化 X-Ray 智能探伤软件系统。系统面向 BGA（球栅阵列）焊点回流焊缺陷检测场景，实现从图像导入、亚像素级焊球轮廓拟合、多维缺陷自动判别、人工复核闭环到合规质检报告输出的全流程数字化质检。

### 1.1 核心检测维度

| 检测维度 | 英文标识 | 工业缺陷机理与算法能力 |
| :--- | :--- | :--- |
| **空洞 / 气泡率检测** | `void` | 基于顶帽形态学背景消除、多峰分水岭粘连解离与严格非交叉圆约束（Circle NMS），精准测量单球内部空洞面积占比，超过阈值自动判 NG |
| **连锡 / 桥连短路检测** | `bridge` | 结合焊球阵列邻域拓扑与球间灰度桥接通道分析，精准检出相邻焊球粘连短路并用警戒红框连线标示 |
| **少锡 / 虚焊检测** | `insufficient` | 基于整板焊球面积统计基准（支持均值 / 中位数两种基准模式），识别面积缩减超标的少锡或虚焊焊点 |
| **综合全项质检** | `comprehensive` | 一次推理同步完成焊球定位、边缘精修及上述全部缺陷维度的协同判定与整板 `PASS / NG` 裁决 |

### 1.2 工业级核心优势

- **复杂背景抗干扰与亚像素贴合**：融合深度学习检测、多阵列自适应拓扑网格重构、自适应高位截断径向梯度精修（Coarse-to-Fine）与 2D 仿射网格一致性校验，有效消除大电感、矩形贴片元件、PCB 过孔与走线干扰，保证焊球轮廓紧密贴合。
- **双引擎硬件自适应**：自动探测 NVIDIA CUDA 显卡并启用 GPU 加速推理；在无独立显卡的工控机或办公主机上自动无缝降级为多核 CPU 并行推理，确保全平台稳定运行。
- **零侵入式工业封装**：核心算法与运行时封装为独立二进制目录，免装 Python 环境与第三方依赖，支持纯离线局域网产线部署。
- **可追溯品保闭环**：内置标准位号映射（如 `A1`、`G4`）、人工复核排除误检闭环、工艺配方 JSON 导入/导出，以及标准化的 Excel 数据工单与 A4 PDF 质检报告。

## 2. 系统运行环境与部署规范

### 2.1 软硬件配置建议

| 资源项 | 最低配置（CPU 兼容运行） | 推荐配置（产线 GPU 极速模式） |
| :--- | :--- | :--- |
| **操作系统** | Windows 10 (64位, 1909 及以上) | Windows 10 / Windows 11 (64位 专业版/企业版) |
| **处理器 (CPU)** | Intel Core i5 / 4 核及以上 | Intel Core i7 / Xeon 8 核及以上 |
| **运行内存 (RAM)** | 8 GB | 16 GB 及以上 |
| **独立显卡 (GPU)** | 无需独立显卡（自动降级 CPU） | NVIDIA GeForce / RTX 系列（显存 ≥ 6 GB，支持 CUDA） |
| **存储空间** | 预留 ≥ 5 GB 可用磁盘空间 | NVMe SSD，预留 ≥ 20 GB（用于长期报表与图像归档） |
| **显示分辨率** | 1366 × 768 | 1920 × 1080 及以上（支持高分屏 DPI 自适应缩放） |

> **显卡驱动提示**：若部署机台配置了 NVIDIA 独立显卡，建议安装官方 WHQL 驱动（驱动版本支持当前 CUDA 运行时即可，无需单独安装 CUDA Toolkit）。如驱动不兼容，系统会自动安全回退至 CPU 模式，不会导致程序崩溃。

### 2.2 标准交付目录结构

将交付压缩包解压至非系统盘目录（例如 `D:\X-Ray_AI_Inspector\`，支持中文路径，建议避免放置于需要管理员写权限的 `C:\Program Files\` 下）：

```text
X-Ray_AI_Inspector/
├── X-Ray_AI_Inspector.exe        # [主程序] 双击启动客户端；支持 --selftest 命令行自检
├── settings.json                 # [配置文件] 持久化保存工艺阈值、界面布局与偏好设置（首次运行自动生成）
├── 用户操作与部署手册.pdf         # [交付文档] 企业级用户操作与部署手册（PDF 版）
├── backend/                      # [外部模型目录]
│   └── best.pt                   # 外部优先加载的模型权重（支持产线热替换）
└── _internal/                    # [底层运行时] 封装的推理引擎与依赖库（严禁修改或删除）
```

> **安全与合规说明**：
> 1. 本软件支持**完全离线运行**，无需连接互联网，无任何数据外传行为，符合半导体与军工/汽车电子产线信息安全隔离要求。
> 2. `_internal/` 目录为系统底层依赖运行时，请勿手动增删或覆盖其中的动态链接库文件。

### 2.3 首次部署检查步骤

1. **解压部署**：将交付包完整解压至目标工控机本地磁盘。
2. **杀毒软件白名单**：若产线终端安装有企业终端安全软件，建议将部署根目录加入信任白名单，避免误拦截底层推理动态库加载。
3. **执行出厂自检**：按 [第 10 节](#10-出厂自检与部署验收规范--selftest) 运行 `X-Ray_AI_Inspector.exe --selftest`，确认退出码为 `0` 且 `selftest_report.txt` 全项 `[ OK ]`。
4. **验证界面启动**：双击 `X-Ray_AI_Inspector.exe`，确认左上角/底部状态栏硬件标识显示正常（GPU 机型显示 `GPU 加速已就绪`，无独显机型显示 `CPU 多核模式`）。

## 3. 快速启动与标准作业流程（SOP）

本节适用于产线操作员（OP）与品保工程师（QE）的日常标准质检作业。

```text
  [1. 启动工作站] ──→ [2. 导入图像/目录] ──→ [3. (可选)ROI裁剪/调参]
                                                      │
  [6. 导出PDF/Excel] ←── [5. 结果复核与定位] ←── [4. 执行一键质检]
```

### 步骤 1：启动工作站
双击 `X-Ray_AI_Inspector.exe`。系统在 2~3 秒内完成深度学习推理引擎初始化与硬件算力自适应探测，默认全屏最大化进入深色防眩光主界面。

### 步骤 2：导入待检 X-Ray 图像
在左侧 **【控制面板】** 选择输入源（完全支持中文及空格路径，支持 `.jpg`、`.jpeg`、`.png`、`.bmp`、`.tif`、`.tiff`）：
- **单板检测**：点击 **【打开单张图片】**，选择单张 X-Ray 图像。
- **批量队列检测**：点击 **【批量检测目录】**，选择包含多张待检图像的文件夹，底部缩略图胶卷栏将自动载入完整队列。

### 步骤 3：确认工艺参数（或局部 ROI 框选）
- 右侧 **【参数配置】** 区域自动加载上次固化的 `settings.json` 工艺配方。若换线切换料号，可点击 **【导入参数】** 一键载入对应料号的 `.json` 配方。
- 若仅需检测拼板中的某一颗特定 BGA 芯片，可在左侧点击 **【框选局部区域裁剪 (ROI)】** 框选目标区域后再检测（详见 [第 7.1 节](#71-局部区域框选裁剪roi)）。

### 步骤 4：一键执行质检
点击左侧高亮主按钮 **【开始执行质检任务】**（批量模式下支持随时点击 **【终止任务】** 中断队列）：
- 后台线程自动完成：焊球目标检测 → 阵列网格拓扑补齐 → 亚像素边缘精修 → 空洞/桥连/虚焊协同筛查。
- 完成后中央视口实时渲染标注结果，右侧仪表盘与缺陷明细表同步刷新。

### 步骤 5：缺陷定位与人工复核
- 在右侧 **【缺陷明细表】** 中**双击任意异常记录**，中央视口将自动居中放大并以激光亮红准星锁定该焊球。
- **长按键盘 `Space`（空格键）** 可瞬时隐藏标注线，对照纯净 X-Ray 原图进行人眼复核。
- 若确认某处为背景特殊工艺导致的误报，可选中该焊球后按 **`R` 键** 标记为【人工复核合格】，系统将实时重算整板良率与 `PASS / NG` 结论。

### 步骤 6：导出合规质检报表
点击左侧底部报表导出按钮：
- **【导出 PDF 报告】**：生成 A4 工业级正式质检报告，用于品保签核与客户出货随附。
- **【导出 Excel 报表】**：生成结构化多工作表数据工单，用于 MES 归档与 SPC 良率统计分析。

### 4.2 工业级语义色彩规范

系统在中央视口、参数数字框、统计卡片与缺陷明细表中执行**全界面统一语义配色**，确保产线人员一眼区分缺陷类别：

| 标注对象 / 状态 | 视觉颜色 | 色值代码 | 含义说明 |
| :--- | :--- | :--- | :--- |
| **正常焊点（PASS）** | 翠绿色 | `#10b981` | 焊球轮廓正常、无超标空洞、无桥连及少锡异常 |
| **工艺微气泡（PASS）** | 清澈电光青 | `#00f2fe` | 焊球内部检出的正常微气孔，总空洞率未超过 NG 阈值 |
| **空洞超标（NG）** | 高饱和明黄色 | `#ffd000` | 焊球内部总空洞面积占比超过设定阈值（默认 `> 25.0%`） |
| **桥连短路（NG）** | 纯正警戒鲜红 | `#dc2626` | 相邻焊球之间存在连锡桥接通道，绘制红色外框与连线 |

| **表格定位聚焦准星** | 激光亮红 | `#ff1744` | 双击右侧缺陷表某行时，视口显示的靶心准星（对应表格深绯红高亮行 `#881337`） |
| **人工复核合格** | 电光青蓝 | `#06b6d4` | 经 QE 工程师人工复判排除误检、改判合格的焊球/桥连 |

### 4.3 视口显示模式与透明度控制

顶部工具栏提供三种视口模式与连续透明度调节（`10% ~ 100%`）：
- **全轮廓模式 (`all_outline`)**：显示所有正常焊球细绿轮廓 + 全部微气泡 + 缺陷高亮标注（默认模式，适合全面核验边缘贴合度）。
- **仅高亮缺陷模式 (`defect_only`)**：隐藏正常焊球，仅突出显示空洞超标、桥连短路与少锡虚焊目标（适合高密度千球 BGA 快速巡检）。
- **纯原图模式 (`raw_image`)**：关闭所有叠加层，展示原始 X-Ray 灰阶底图。

## 6. 多维质检算法、参数调谐与工艺配方管理

### 6.1 核心可调参数一览

所有参数均支持**滑块拖拽粗调**与**数值输入框（含 `+ / -` 步进按钮）精调**双向联动：

| 参数名称 | `settings.json` 键名 | 出厂默认值 | 可调范围 / 步长 | 工业含义与调参建议 |
| :--- | :--- | :--- | :--- | :--- |
| **质检算法模式** | `inspection_mode` | `comprehensive` | 综合 / 仅气泡 / 仅桥连 / 仅虚焊 | 常规全检保持 `comprehensive`；专项排查可单选子模式提速 |
| **焊球识别置信度** | `conf_threshold` | `0.20` (`20.0%`) | `10.0% ~ 90.0%`（步长 `1.0%`） | 控制一阶段焊球检出灵敏度。过低易引入背景杂点，过高可能漏检低对比度焊球；常规推荐 `18% ~ 30%` |
| **空洞超标判定阈值** | `ng_void_threshold` | `0.25` (`25.0%`) | `1.0% ~ 50.0%`（步长 `0.5%`） | 单颗焊球内部空洞面积占比上限。IPC-A-610 标准常用 `25.0%`，高可靠车规/军工产线可收严至 `15.0% ~ 20.0%` |
| **少锡虚焊缩减阈值** | `undersize_threshold` | `0.20` (`20.0%`) | `1.0% ~ 50.0%`（步长 `0.5%`） | 焊球实测面积低于整板基准面积的缩减比例阈值。默认 `20.0%` 表示面积小于基准 `80%` 即判少锡虚焊 |
| **面积统计基准模式** | `area_reference_mode` | `mean` | `mean`（均值） / `median`（中位数） | 少锡判定的整板参考基准；若板内存在少量极端异常球，建议选用 `median` 抗离群干扰 |

> **联动提示**：当修改了会影响推理的参数时，左侧主按钮会自动变为高亮提示 **【重新执行质检 (参数已修改)】**；而仅调整判定阈值（如空洞率门槛或少锡门槛）时，系统支持基于内存结果进行**毫秒级即时重判**并刷新结论与表格。

### 6.2 工艺配方管理（多料号快速换线）

右侧参数区底部内置四枚配方管理按钮，支持不同芯片料号（如 0.4mm pitch 手机 SoC、0.8mm pitch 工业主控）的标准固化与跨机台同步：

- **【保存为默认】**：将当前界面全部参数持久化写入工作站根目录 `settings.json`，下次开机自动生效。
- **【恢复默认】**：一键重置为出厂标准（置信度 `0.20`、空洞阈值 `25.0%`、少锡阈值 `20.0%`、综合全检模式、全轮廓视图）。
- **【导出参数】**：将当前工艺阈值导出为标准 JSON 配方文件（格式标识 `X_RAY_INSPECTOR_RECIPE_V1`，如 `Recipe_BGA256_Class3.json`），便于跨产线机台分发。
- **【导入参数】**：载入外部 JSON 配方文件，自动完成数值合法性边界校验并即时生效。

## 7. 局部 ROI 框选与人工复核闭环机制

### 7.1 局部区域框选裁剪（ROI）
当 X-Ray 采集的是整块多芯片 PCBA 大图，而只需检验其中某一颗 BGA 封装芯片时：
1. 点击左侧面板 **【框选局部区域裁剪 (ROI)】**，中央画布进入交互式矩形框选模式；
2. 鼠标拖拽框出目标 BGA 区域（可拖曳四边与角点微调范围）；
3. 点击 **【确认裁剪】** 锁定局部区域，随后点击 **【开始执行质检任务】** 即可只针对该芯片高精度质检；
4. 检测完毕后点击 **【恢复完整大图】** 即可随时回到原始全幅图像。

### 7.2 人工复核与误检排除闭环
针对极端复杂双面贴装板偶发的人工争议缺陷，系统提供完整的 QE 复核机制：
1. 在缺陷明细表双击定位该异常焊球，按住 `Space` 透视原图确认；
2. 若确认属于非缺陷误报，按键盘 **`R` 键**（或通过表格右键/复核操作）将其标记为 **人工复核合格**；
3. 该焊球在视口中变为电光青蓝（`#06b6d4`），右侧统计面板的 NG 数量与整板 `PASS / NG` 结论**实时重算**；
4. 后续导出的 PDF 报告与 Excel 明细表中均会忠实记录复核后的最终裁定状态，确保品保审计账实相符。

## 8. 质检报表导出与数字归档

点击左侧面板底部导出按钮后，系统弹出原生文件保存对话框（默认按 `样品名 + 时间戳` 自动命名防覆盖），支持保存至本地磁盘或企业局域网共享路径。

### 8.1 Excel 结构化数据工单（`.xlsx`）
适用于品保 SPC 趋势分析、良率月报汇总与 MES 系统对接，包含多张标准化工作表：

- **桥连缺陷明细表**（存在桥连时）：记录发生短路的焊球对编号、中心坐标与桥接判定依据。

### 8.2 A4 工业级 PDF 质检报告（`.pdf`）

- 工艺判定标准摘要与整板 `PASS / REJECT` 醒目结论印章；
- 高清质检标注结果图（含焊球轮廓、空洞、桥连与少锡标记）；
- 关键指标汇总表、缺陷焊球重点明细列表及品保审核签字栏。

## 9. 产线模型热替换与版本维护

系统采用**外部模型优先加载架构**，支持在产线导入新封装料号（NPI）或迭代新模型权重时，无需重新编译或重装软件即可实现秒级热更新。

### 9.1 权重加载优先级
软件启动时按以下顺序自动检索模型权重文件：
1. `<安装目录>\backend\best.pt`（**最高优先级，推荐用于产线热替换**）
2. `<安装目录>\best.pt`
3. 安装包内置出厂基准权重（兜底保障，防止外部文件误删导致无法启动）

### 9.2 现场热替换操作步骤
1. 正常关闭正在运行的 `X-Ray_AI_Inspector.exe`；
2. 备份原有 `<安装目录>\backend\best.pt`（例如重命名为 `best_backup_YYYYMMDD.pt`）；
3. 将新版本权重文件命名为 `best.pt` 并放入 `<安装目录>\backend\`；
4. 执行出厂自检命令 `X-Ray_AI_Inspector.exe --selftest` 验证新模型推理与报表链路全部通过；
5. 双击启动主程序投入生产。

## 10. 出厂自检与部署验收规范（`--selftest`）

系统内置静默全链路自检引擎，**无需启动图形界面**即可自动校验依赖库、GPU/CPU 运行时、模型推理、四条质检流水线与报表导出，适用于新机交付验收、显卡驱动升级回归及现场排障。

### 10.1 执行方式
在软件安装目录打开命令行终端（Windows 文件资源管理器地址栏输入 `cmd` 并回车），执行：

```powershell
X-Ray_AI_Inspector.exe --selftest
```

**常用可选参数**：

| 参数 | 说明 |
| :--- | :--- |
| `--image <图像路径>` | 指定产线真实 X-Ray 样例图参与验收测试；未指定时自动搜索样例目录，若无样例则自动合成标准焊球阵列测试图 |
| `--no-cpu` | 跳过 GPU 机台上的附加 CPU 降级复测，缩短验收耗时 |

### 10.2 自检覆盖项（6 大模块）
1. **核心依赖库校验**：逐项导入 `torch`、`torchvision`、`cv2`、`numpy`、`scipy`、`pandas`、`openpyxl`、`reportlab`、`matplotlib`、`PySide6` 并记录版本号。
2. **CUDA/cuDNN 运行时校验**：核查 GPU 加速所需的核心动态库完整性。
3. **硬件探测与权重定位**：按主程序同口径解析 GPU/CPU 计算设备并验证 `best.pt` 可正常载入。
4. **四维流水线回归**：依次执行 `void`（气泡）、`bridge`（桥连）、`insufficient`（虚焊）与 `comprehensive`（综合）全链路推理，记录单帧耗时与检测统计。
5. **报表链路验证**：使用与客户端一致的会话逻辑导出 Excel 与 PDF 文件，并校验产物非空。
6. **CPU 降级复测**：在 GPU 机台上额外执行一次 CPU 模式推理，确保异构环境兼容性。

### 10.3 验收判读与交付签核清单
- 终端逐项打印 `[ OK ]` / `[INFO]` / `[WARN]` / `[FAIL]`，完整日志同步归档至 `<安装目录>\selftest_report.txt`；
- 进程退出码为 **`0`** 表示全部验收通过，**`1`** 表示存在失败项；
- 无独立显卡主机提示 `[WARN] CUDA 不可用，将只验证 CPU 链路` 属正常预期，不影响验收通过；
- 自检产生的临时测试报告位于 `<安装目录>\selftest_output\`，验收完成后可直接清理。

**甲方现场部署验收检查表（建议留存）**：

| 验收项 | 验收方法 | 预期结果 | 确认 |
| :--- | :--- | :--- | :---: |

## 11. 常见故障排查矩阵（Troubleshooting）

| 故障现象 | 可能原因 | 标准排查与处置步骤 |
| :--- | :--- | :--- |
| **双击程序后等待 2~3 秒才出现界面** | 首次启动加载 PyTorch 算子库与硬件嗅探 | 属正常初始化行为；进入主界面后单张检测为毫秒级响应 |
| **有 NVIDIA 独显但状态栏显示 CPU 模式** | 显卡驱动过旧、CUDA 运行时被安全软件拦截或 `settings.json` 中 `hardware_device` 被锁定为 `"cpu"` | ① 检查 `settings.json` 中 `"hardware_device"` 是否为 `"auto"`；② 更新 NVIDIA 官方驱动；③ 运行 `--selftest` 查看具体 CUDA 诊断日志 |
| **软件闪退或提示缺少 DLL** | `_internal/` 目录文件被杀毒软件隔离或解压不完整 | 将安装目录加入杀毒软件白名单，重新完整解压交付包后运行 `--selftest` 验证 |
| **中文路径或共享盘图片无法导入** | 网络共享盘断连、文件损坏或后缀不在支持列表 | 系统底层原生支持中文路径；请确认文件为 `.jpg/.png/.bmp/.tif` 有效图像且当前 Windows 账户具备读取权限 |
| **导出 PDF / Excel 时提示写入失败** | 目标同名文件正在被 WPS / Excel / Adobe Reader 占用，或目标目录无写权限 | 关闭正在打开的同名旧报表，或另存至有写权限的本地非系统盘目录 |
| **界面参数误调乱、检测结果异常** | 阈值被人为拉至极端值（如空洞门槛设为 `1%`） | 点击右侧面板 **【恢复默认】** 一键复位出厂标准，或重新导入经过验证的工艺配方 JSON |
| **单个焊球在复杂器件背景上被误判** | 极端双面元件叠影导致的边界争议 | 双击缺陷表定位该球 → 按住 `Space` 透视原图确认 → 按 `R` 键执行人工复核改判合格 |
